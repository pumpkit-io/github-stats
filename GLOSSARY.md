# GitHub statistics

Terms for describing pull request activity across the organization.

## Language

**Created pull request count**:
The number of pull requests created in a period, regardless of their current state.

**Merged pull request count**:
The number of pull requests merged in a period, grouped by their merge date.

**Cumulative pull request count**:
The running total of created or merged pull requests within the selected date range, starting at zero.
